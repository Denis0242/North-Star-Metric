# KPI Definitions

| KPI | Definition | Why It Matters |
|---|---|---|
| Activation Rate | Average rate of users reaching early meaningful engagement | Measures onboarding and early product value |
| Conversion Rate | Average rate of users completing the target product action | Measures product/business outcome |
| D30 Retention | Average 30-day retained user rate | Measures long-term product value |
| Churn Rate | Average churn behavior rate | Measures user loss risk |
| Avg Engagement Score | Average behavioral engagement score | Measures product health intensity |
| Revenue Per User | Average user-level revenue | Connects engagement to monetization |
| Feature Adoption Rate | Average adoption rate by primary feature | Shows which features drive usage |
